# Робот с движением по линии #

Программа предназначена для управления колесного робота для его автоматического движения по черной линии на белом фоне с возвращением в случае потери линии

**Подготовка:**
1. Нажатие кнопки первый раз - калибровка белого цвета (датчики должны находиться на белом фоне)
2. Нажатие кнопки второй раз - калибровка черного цвета (датчики должны находиться на черном фоне)
3. Нажатие кнопки третий раз - запуск робота

Робот двигается по линии
При потере проверяется какой из датчиков (левый или правый) последним определил линию, в зависимости от этого робот двигается либо вправо+назад, либо влево+назад.
